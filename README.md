# Barrage

Barrage bloque automatiquement sur vos réseaux sociaux les comptes d'une liste collaborative et open source.

- Site et installation : https://barrage-app.github.io/Barrage/
- Code de l'extension : `extension/`
- Listes de comptes : `lists/`

## Demander un retrait de la liste

Votre compte figure dans la liste et vous souhaitez en être retiré ? Écrivez à **barrage.app@protonmail.com** en indiquant :

- le réseau concerné (X, Instagram, TikTok…) ;
- le nom du compte (@nom).

Chaque demande reçoit une réponse dans un délai d'un mois maximum.
